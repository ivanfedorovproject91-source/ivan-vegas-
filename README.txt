IVAN VEGAS — one-page artist website

FILES
- index.html: page content and metadata
- styles.css: responsive layout, typography, colors, motion
- script.js: mobile navigation and current year
- assets/ivan-vegas-logo.png: supplied artist logo
- site-mockup.png: visual design mockup (if included)

HOW TO VIEW
Open index.html in a browser. For best typography, an internet connection is needed for Google Fonts; the page otherwise works without a build step.

CUSTOMIZE
Edit links and copy in index.html. Colors and spacing are defined at the top of styles.css.
